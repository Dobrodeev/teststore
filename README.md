# КанцМаркет — интернет-магазин канцтоваров

Стек: **Express 5** + шаблоны EJS, **PostgreSQL** (`pg`), прайс-лист на **DataTables**.
Страницы рендерит сервер, каталог и заявки хранятся в базе.

## Запуск

```bash
npm install
npm run db:init     # первый раз: отдельный локальный кластер PostgreSQL на порту 5441 (.pgdata/)
npm start           # http://localhost:3100
```

Следующие запуски: `npm run db:start` → `npm start`. Остановить базу: `npm run db:stop`.

Вместо локального кластера подойдёт любой PostgreSQL — параметры подключения в `.env` (образец: `.env.example`).
При старте сервер сам создаёт таблицы (`db/schema.sql`) и, если каталог пуст, наполняет его из `data/*.json`.

## Страницы

| Адрес | Страница |
| --- | --- |
| `/` | Главная |
| `/catalog` | Каталог (фильтры `?cat=`, `?badge=`, поиск `?q=`) |
| `/price` | Прайс-лист (DataTables: поиск, сортировка, постраничный вывод) |
| `/o-nas` | О нас |
| `/kontakty` | Контакты и форма заявки |
| `/robots.txt`, `/sitemap.xml` | генерируются автоматически |

Старые адреса (`/catalog.html`, `/kontakty.html` и т. д.) отдают 301 на новые.

## База данных

| Таблица | Содержимое |
| --- | --- |
| `categories` | категории каталога |
| `products` | товары |
| `orders` | заявки с формы: контакты, сообщение, товары из корзины, сумма |

Каталог редактируется в `data/categories.json` и `data/products.json`; после правок — `npm run seed`
(перезаписывает категории и товары, заявки не трогает).

Заявки сохраняются запросом `POST /api/orders`. Админ-панели и уведомлений нет — посмотреть заявки можно запросом:

```sql
SELECT id, created_at, name, phone, total, items FROM orders ORDER BY id DESC;
```

## Где что менять

| Что | Где |
| --- | --- |
| телефон, адрес, график, ссылка на карту | `src/site.js` |
| адрес сайта для canonical, sitemap, Open Graph, JSON-LD | `SITE_URL` в `.env` |
| тексты страниц | `views/pages/*.ejs` |
| шапка, футер, корзина, карточка товара | `views/partials/` |
| стили и клиентские скрипты | `public/css`, `public/js` |

## Структура

```
server.js             точка входа: схема, первичное наполнение, запуск
src/app.js            маршруты страниц, API заявок, SEO
src/store.js          запросы к базе
src/db.js             подключение, схема, наполнение
src/site.js           контакты и настройки магазина
db/schema.sql         схема базы
data/                 исходные данные каталога
views/                шаблоны EJS
public/               css, js, изображения
scripts/              локальная база, наполнение, статический экспорт
```

## Деплой

Сайту нужен Node.js-сервер и PostgreSQL (VPS, Render, Railway, Cloud Run + Cloud SQL и т. п.).

Firebase Hosting умеет отдавать только статику, поэтому для него есть экспорт:

```bash
npm run export            # готовые страницы и статика → firebase-dist/
npm run firebase:deploy   # seed → export → firebase deploy --only hosting
```

В статической версии работают каталог, прайс-лист и корзина, но **форма заявки не сохраняет данные** —
ей нужен запущенный сервер.

Скрипты `upload.*` / `download.*` остались от прежней версии и обмениваются данными с Firestore; сайт их не использует.
